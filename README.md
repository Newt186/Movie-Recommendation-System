# 🎬 Movie Recommendation System

A simple **Movie Recommendation System** built using Python and Machine Learning.

The system recommends movies similar to a selected movie by analyzing movie genres using **TF-IDF Vectorization** and **Cosine Similarity**.

## 📌 Features

- MovieLens dataset
- Data cleaning
- Exploratory Data Analysis (EDA)
- TF-IDF feature extraction
- Cosine similarity
- Content-based movie recommendations
- Flask web application
- REST API

## 🧠 How It Works

The recommendation process follows these steps:

```text
MovieLens Dataset
       ↓
Data Cleaning
       ↓
Movie Genres
       ↓
TF-IDF Vectorization
       ↓
Cosine Similarity
       ↓
Recommended Movies
